# HitMeUp

A prototype website for finding tennis, pickleball and padel partners in NYC, Long Island and the Hamptons.

**Live site:** https://domanderson03.github.io/Hitmeup/

## What it does
- Browse players by level and find hitting partners
- Find coaches and courts in your area
- Sign up and log in (accounts stored securely with Supabase)

The player and coach profiles are sample data to show how matching works.

## Built with
- HTML, CSS and JavaScript, built with AI coding tools (Claude)
- Supabase for user accounts and the database
- Hosted on GitHub Pages
